## 1. Hero: 3D и «живой» фон

### P0 — Сделать 3D сцену заметной и интерактивной

**Проблема:** Частицы и линии почти не видны, параллакс слабый, нет ощущения «delivery engine».

**Что сделать в коде:**

| Файл | Действие |
|------|----------|
| `src/components/three/hero-scene.tsx` | Увеличить размер частиц (например до 0.03), поднять opacity до 1. Добавить второй слой частиц ближе к камере (мелкие, яркие). |
| `hero-scene.tsx` | Усилить параллакс камеры: множитель с 0.5 до 0.8 по X/Y. Добавить лёгкий zoom-in при движении мыши к центру. |
| `hero-scene.tsx` | Сделать «ленту» (FlowingLines) толще и ярче: увеличить radius трубки, opacity 0.55 → 0.7, добавить 2–3 линии с другим цветом (accent). |
| `src/components/sections/hero.tsx` | Убрать или ослабить верхний градиент overlay (from-bg-primary/40), чтобы 3D читался. Оставить только нижний градиент для читаемости текста. |

**Дизайн:** Фон не должен перебивать текст. Проверить контраст по WCAG.

## 2. Кейсы: карточки не шаблонные

### P0 — Визуальное разнообразие карточек

**Проблема:** Все карточки одинаковые, нет «артефактов», мало медиа.

**Что сделать:**

| Файл | Действие |
|------|----------|
| `src/components/sections/featured-cases.tsx` | **Первую** карточку (главный кейс) сделать шире и выше: свой вариант фона — например крупная сетка или «схема» (SVG линии/точки), плюс маленький артефакт: «IT-01…IT-05» или «47 scenarios» в углу в стиле бейджа/метки. |
| `featured-cases.tsx` | Остальные карточки: варьировать фоны — одна с диагональными полосами (очень тонкими), другая с точечным паттерном, третья с градиентным пятном в углу. Не менять структуру (тег, заголовок, описание, ссылка), только фон и мелкие детали. |
| `cases-data.ts` | Добавить опциональное поле `visualHint` для кейса (например «integration_tests», «dex», «kyc») и в карточке выводить маленький артефакт (иконка или короткая подпись) по этому полю. |

---

### P1 — Артефактные карточки на странице кейса

**Бриф:** «Real artifact UI cards (reports, checklists, test catalogs)».

**Что сделать:**

| Файл | Действие |
|------|----------|
| `src/app/cases/[slug]/case-detail-content.tsx` | Для кейса 1 (web3-l1-dex): добавить блок «Артефакты» после Solution или Deliverables: 2–3 карточки в стиле «документ» — например «Integration Test Catalog (IT-01…IT-05)», «Pre-deployment checklist», «RPC/wallet matrix». Стиль: узкая карточка, моноширинный шрифт, рамка, иконка «документ». |
| `case-detail-content.tsx` | Опционально для других кейсов: одна артефактная карточка с ключевым deliverable (например «KYC flow draft», «Token utility model»). |

## 6. Чеклист перед «релизом» премиум-версии

- [ ] Hero: 3D сцена хорошо видна, параллакс и «лента» читаются.
- [ ] Hero: при скролле либо смена состояния 3D, либо появление блока «Capabilities».
- [ ] Кейсы: первая карточка выделена размером/фоном/артефактом; остальные визуально различаются.
- [ ] На странице кейса 1 есть блок «Артефакты» с 2–3 карточками в стиле документов.
- [ ] Процесс: асимметричная сетка и разный визуал шагов; hover и stagger.
- [ ] Final CTA: асимметрия (текст + blob/форма), шум/сетка, магнитные кнопки.
- [ ] Шапка: лёгкая анимация при скролле и hover; CTA с магнитным эффектом.
- [ ] Глобально: шум чуть заметнее; разные отступы секций.
